# Handwritten-Digit-Classification
Handwritten Digit Classification using KNN and SVM Machine Learning Algorithms.
## Project Overview
This project recognizes handwritten digits from 0 to 9 using Machine Learning.

## Dataset
UCI Optical Recognition of Handwritten Digits Dataset.

## Algorithms Used
- K-Nearest Neighbors (KNN)
- Support Vector Machine (SVM)

## Project Features
- Data Inspection
- Data Visualization
- Feature Scaling
- Model Training
- GridSearchCV Optimization
- Accuracy Comparison
- Confusion Matrix
- Model Evaluation

## Technologies
Python, NumPy, Pandas, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook.
